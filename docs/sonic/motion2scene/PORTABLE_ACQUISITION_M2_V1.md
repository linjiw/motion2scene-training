## Provenance and reconstruction

Every corpus exports pickle-free trajectories, measured contacts, causal sensor
inputs, command histories, original assessment/source snapshots and complete
teacher continuations. Fit provenance retains exact M0/M1/M2 policies, teachers,
ridge regularization λ=10, the adopted measured-tie initializer and historical
replay weights. Student one binds its generating M0 policy; student two binds M1.
The reader uses the original independently audited replay weights. It does not
regenerate the full historical physical-gap audit or relabel fitting residuals
as physical outcomes.

The original retained bootstrap belongs to `seed93203_analytic_contrast`.
`historical_startup/` includes the original unknown startup assessment, the
independently recorded zero physics steps, the separate conservative 1,192-step
reservation, and the failed initial fit. Its seven subsequent recorded bootstrap
captures contribute 8,344 steps already included above and are counted once.
All seven original trajectory identities and hashes were checked before packing.
`source_audit.json` and `candidate_pool_result.json` retain geometric proposal
accounting separately from physical cost; logical arm-equivalent queries are
not extra measured computation.

The full reader passed on both the original export and the actual relocated
archive extraction with Python 3.11.16 and NumPy 2.4.6 under `python -I`.
The validation guard denied original repository/experiment reads, simulator
imports and writes to the release while permitting installed NumPy. The reader
now suppresses generated bytecode before its local imports. This is a
Python-level trusted-reader check, not an operating-system sandbox. The initial
NumPy-path denial and earlier smoke-test bytecode are retained in validation
history; neither altered a physical acquisition or the final release.

The archive preserves all 17,233 member paths and bytes; 12,948 tar hardlinks
refer to earlier identical regular files. An actual GNU tar extraction into a
fresh directory verified all 15,162 file paths against the source inventory.
Treat extracted hardlinked files as immutable; editing one in place changes its
aliases. The compact package retains failures and corpus identities. Raw
pretrained weights and complete motion/reference banks are excluded; recorded
reference commands remain execution data. Existing repository/upstream notices
are included. This is a local workspace release, with no public upload claimed.

## Reproduction

Extract into a fresh directory, install the bundled NumPy requirement, and write
reconstruction outputs outside the release:

```bash
mkdir /absolute/path/to/new-extraction
tar -xzf /absolute/path/to/m2s-acquisition-M2-portable-20260909-v1-hardlinks.tar.gz \
  -C /absolute/path/to/new-extraction
cd /absolute/path/to/new-extraction/m2s-acquisition-M2-portable-20260909-v1
python3 -m pip install -r tools/portable_baseline/requirements.txt
OPENBLAS_NUM_THREADS=1 python3 \
  tools/portable_baseline/scripts/research/motion2scene_acquisition_dataset_baseline.py \
  --release . --out /absolute/path/to/new-reconstruction
```

The reader rejects incomplete corpus/model inventories, changed chronological
teacher prefixes and any recorded argmax difference even when coefficient
errors are small. It needs no simulator, original experiment directory or motion
weights for this offline task. Physical reproduction still needs the separately
licensed runtime assets.
