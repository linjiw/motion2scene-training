# V3 proposal erratum: registered script diagnostic

This [immutable erratum](TRAVERSAL_PROTOCOL_AMENDMENT_V3_PROPOSED_ERRATUM_V1.json) reconciles the [original proposed protocol](TRAVERSAL_PROTOCOL_AMENDMENT_V3_PROPOSED.md) with the independently registered development script review. Both remain **proposed; no evaluation protocol or baseline parameters are adopted**. The original JSON, its SHA-256 companion, and all V2/V3 geometry remain unchanged.

The proposal's 90-setting grid described future ranking by actual passage and measured time on a complete matched seven-schedule development corpus. It was never executed. The registered review instead enumerates **72 diagnostic configurations**: free-height thresholds `{1.28, 1.32, 1.36, 1.40}` × immediate prior band counts `{1, 2}` × later prior band counts `{1, 2, 3}` × sustained hazard counts `{1, 2, 3}`. Enumeration follows this product order, with the sustained count varying fastest. The [registration](/home/linjiw/research-data/groot-wbc/m2s-schedule-script-offline-review-v1/registration.json) has SHA-256 `027615d1feea8baf493c328e40ebceacda5787151772858a8e49a284eaa3cb43`.

Every configuration is reported; no best setting or tie-break between configurations is selected. Within one script execution, the first currently legal matching schedule in registered request order wins. The 24 input episodes are the nine three-option development teachers and fifteen development policy comparisons. Their old 0.5-second/26-frame feature reconstruction must match exactly at ticks 15, 50 and 70 before the proposed two-second histories are read. Sequential diagnostics use only six actual never-adapted neutral trajectories and stop at the first predicted adaptation. They do not invent subsequent states or physical outcomes for another schedule.

Agreement with an existing option family is a diagnostic, not seven-schedule passage or cost. A strong baseline still needs a separately registered performance-selection rule, sufficient actual development evidence, runtime validation, and frozen parameters before reserved evaluation. The sweep owner confirmed the 72-setting registration preceded any sweep readouts and that the proposal's 90-setting grid was not used.

The separate protocol validator now requires the canonical original V3 geometry-lock digest, rather than accepting any self-consistent replacement lock. It also requires hash-checked evidence references for every adoption gate. The 27 focused tests include replacement-lock and missing/altered gate-evidence regressions. These checks preserve the planned panel; they do not adopt it or establish physical outcomes.
